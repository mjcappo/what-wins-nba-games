# What Actually Wins NBA Games? Home Court, Threes, and Rest

An analysis of 19 NBA regular seasons (2003–04 through 2021–22) to find which factors actually drive wins.

## Questions
1. Has home-court advantage shrunk over time?
2. Does three-point shooting accuracy affect winning, and has that changed over time?
3. Do back-to-back games hurt teams?

## Data
- Source: [NBA games data](https://www.kaggle.com/datasets/nathanlauga/nba-games) by Nathan Lauga on Kaggle, built from [stats.nba.com](https://www.nba.com/stats)
- Files used: games.csv, teams.csv

## Tools
Python (pandas), SQLite, Tableau Public
